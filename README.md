# Python Algoritma ve Temel Uygulama Çalışmaları

Bu depoda, Python programlama dilini öğrenme ve pratik yapma sürecimde geliştirdiğim temel algoritma, fonksiyon ve veri yapısı uygulamaları yer almaktadır.

---

###  İçerik ve Projeler

* **`guvenli_sifre_kontrolu.py`:** 
  Kullanıcıdan alınan şifrelerin uzunluk, büyük/küçük harf ve rakam kurallarına uygunluğunu denetleyen Python fonksiyonları.

* **`stok_takip_ve_uyari_sistemi.py`:** 
  Ürün stok seviyelerini izleyen, kritik stok uyarıları veren ve toplam stok değerini hesaplayan otomasyon mantığı.

* **`karakter_veri_filtreleme.py`:** 
  Sözlük (Dictionary) yapıları üzerinde `lambda` ifadeleri ve `list comprehension` yöntemleriyle dinamik veri sorgulama ve filtreleme çalışmaları.

* **`kisisel_bilgi_formu.py`:** 
  Kullanıcı girdilerini alarak veri işleme ve string biçimlendirme yöntemlerinin uygulanması.

---

### Kullanılan Teknolojiler
* **Dil:** Python 3.x
* **Kavramlar:** Fonksiyonlar, Döngüler, Veri Yapıları (List, Dict), Lambda Expressions, Algoritma Mantığı
